#  New Year Countdown – Java Swing

A Java Swing–based animated New Year countdown application that displays a countdown from 10 to 0 with smooth font animation, gradient text effects, and a festive GIF background.  
At the end of the countdown, a celebratory **“HAPPY NEW YEAR”** message is shown.

---

##  Features
- Animated countdown using **Java Swing**
- Smooth **font size grow/shrink animation**
- Gradient-colored text rendering
- Festive **GIF background**
- Clean and responsive UI
- Thread-safe animation using `javax.swing.Timer`

---

##  Technologies Used
- Java
- Java Swing (GUI)
- AWT Graphics & Graphics2D
- Core Java concepts
